# 🌸 Iris K-Means Clustering

An interactive **Machine Learning web application** that uses the K-Means Clustering algorithm to group Iris flowers based on their sepal and petal measurements. Built with Python and Flask, the project provides cluster prediction and an interactive dashboard for exploring clustering results.

## 📌 Project Overview

The Iris K-Means Clustering project demonstrates unsupervised machine learning using the famous Iris flower dataset. The K-Means algorithm groups flowers into three clusters based on their measurements without requiring predefined species labels during training.

The web application allows users to enter flower measurements and predict the cluster to which a flower belongs.

## 🎯 Objectives

- Implement K-Means clustering for Iris flower data.
- Apply feature scaling using StandardScaler.
- Predict clusters for new flower measurements.
- Build an interactive web application using Flask.
- Visualize clustering results through an analytics dashboard.
- Provide a responsive interface with dark and light themes.

## ✨ Features

- **K-Means Clustering:** Groups Iris flower measurements into three clusters.
- **Cluster Prediction:** Predicts the cluster for user-provided measurements.
- **Feature Scaling:** Uses StandardScaler to standardize input features.
- **Interactive Dashboard:** Provides a user-friendly web interface.
- **Data Visualization:** Displays charts and clustering analytics.
- **Dark/Light Mode:** Supports different visual themes.
- **Responsive Design:** Designed for desktop and mobile screens.
- **Input Validation:** Checks the measurements entered by the user.

## 🌿 Input Features

The model uses four numerical features:

| Feature | Description |
|---|---|
| Sepal Length | Length of the flower's sepal |
| Sepal Width | Width of the flower's sepal |
| Petal Length | Length of the flower's petal |
| Petal Width | Width of the flower's petal |

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Machine Learning:** Scikit-learn
- **Algorithm:** K-Means Clustering
- **Feature Scaling:** StandardScaler
- **Web Framework:** Flask
- **Frontend:** HTML, CSS, JavaScript
- **Data Visualization:** Chart.js
- **Model Storage:** Pickle (`.pkl` files)

## 🧠 Machine Learning Workflow

1. Load the Iris dataset.
2. Select the four numerical flower features.
3. Standardize the features using StandardScaler.
4. Train the K-Means clustering model with three clusters.
5. Save the trained model and scaler.
6. Load the saved files into the Flask application.
7. Accept flower measurements from the user.
8. Scale the input using the saved scaler.
9. Predict and display the assigned cluster.

## 📊 Understanding the Results

The application assigns an input flower to one of the three clusters generated by K-Means.

- **Cluster 0**
- **Cluster 1**
- **Cluster 2**

Cluster numbers are algorithm-generated group identifiers. They do not automatically represent specific Iris species, and their numbering can vary between model runs.
